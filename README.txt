# SHABBONA ENGLISH

Shabbona English — ingliz tilini A2, B1, B2 va C1 darajalarida mashq qilish uchun tayyor web-ilova.

## Ishga tushirish (VS Code)
1. ZIP arxivni kompyuteringizga yuklab oling va oching.
2. VS Code dasturida `SHABBONA_ENGLISH` papkasini oching.
3. `index.html` faylini oching.
4. Tavsiya: VS Code ichida **Live Server** kengaytmasini o‘rnating.
5. `index.html` ustiga o‘ng tugma bosing va **Open with Live Server** ni tanlang.

Live Server bo‘lmasa, `index.html` faylini brauzerda ham ochishingiz mumkin.

## Imkoniyatlar
- A2, B1, B2, C1 darajalarini tanlash
- So‘z kartochkalari, tarjima va misollar
- Brauzer orqali inglizcha ovoz chiqarib o‘qish
- Grammatika testlari va izohlar
- Reading va Listening mashqlari
- Mock testlar va natijalarni ko‘rish
- Progressni brauzerning localStorage xotirasida saqlash
- Telefon va kompyuter ekranlariga mos dizayn

## Fayllar
- `index.html` — ilova tuzilishi
- `style.css` — dizayn
- `app.js` — ilova logikasi va o‘quv materiallari
- `assets/shabbona-logo.png` — Shabbona logotipi

Eslatma: progress aynan shu brauzer va qurilmada saqlanadi. Google Fonts internet bo‘lsa yuklanadi; qolgan asosiy ilova offline ham ishlaydi.
